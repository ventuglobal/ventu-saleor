# landing-global (ventuglobal.com)

Sitio corporativo de Ventu con formulario de contacto para inversionistas, partners y talento.
Código recuperado del servicio `landing-global` de Railway; ver `docs/railway.md`.

```bash
npm install && DATABASE_URL=... npm start   # http://localhost:8080
railway up --service landing-global         # desplegar
```
